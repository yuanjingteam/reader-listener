# Koodo Reader 需求文档

## 1. 项目概述

### 1.1 项目简介
Koodo Reader 是一款开源的跨平台电子书阅读器，支持 Windows、macOS、Linux、Android、iOS 和 Web 平台。该项目旨在为用户提供一个功能强大、界面简洁的数字阅读体验。

### 1.2 项目目标
- 提供多平台一致的阅读体验
- 支持多种主流电子书格式
- 提供丰富的阅读功能和个性化设置
- 实现跨设备的数据同步和备份
- 支持多语言国际化

### 1.3 版本信息
- 当前版本：2.2.6
- 开发语言：TypeScript
- 技术栈：Electron + React

## 2. 功能需求

### 2.1 格式支持

#### 2.1.1 电子书格式
| 格式 | 扩展名 | 支持状态 |
|------|--------|----------|
| EPUB | .epub | ✅ 完全支持 |
| PDF | .pdf | ✅ 完全支持 |
| Mobipocket | .mobi | ✅ 支持（无DRM） |
| Kindle | .azw3, .azw | ✅ 支持（无DRM） |
| 纯文本 | .txt | ✅ 完全支持 |
| FictionBook | .fb2 | ✅ 完全支持 |
| 漫画书 | .cbr, .cbz, .cbt, .cb7 | ✅ 完全支持 |
| 富文本 | .md, .docx | ✅ 支持 |
| 超文本 | .html, .xml, .xhtml, .mhtml, .htm | ✅ 支持 |

### 2.2 核心功能模块

#### 2.2.1 图书管理
**功能描述**
- 导入本地图书文件
- 批量导入图书
- 删除图书（支持软删除和硬删除）
- 编辑图书元数据（书名、作者、封面等）
- 图书分类和书架管理
- 图书搜索和筛选
- 图书排序（按书名、作者、添加时间等）
- 查看图书详细信息

**用户场景**
- 用户可以通过拖拽或文件选择器导入图书
- 用户可以创建多个书架进行分类管理
- 用户可以通过书名、作者等关键词快速查找图书

#### 2.2.2 阅读器功能
**功能描述**
- 单栏/双栏/连续滚动布局
- 翻页动画效果
- 章节导航
- 目录快速跳转
- 阅读进度保存和恢复
- 全屏阅读模式
- 页面缩放

**用户场景**
- 用户可以根据阅读习惯选择不同的布局模式
- 用户可以通过目录快速跳转到感兴趣的章节
- 阅读进度自动保存，下次打开时继续阅读

#### 2.2.3 阅读设置
**功能描述**
- 字体大小调节
- 字体家族选择
- 行间距调节
- 段落间距调节
- 背景颜色自定义
- 文字颜色自定义
- 页边距调节
- 亮度调节（仅Electron）
- 夜间模式
- 主题颜色设置

**用户场景**
- 用户可以根据环境光线调整阅读界面
- 用户可以自定义字体和间距以获得最佳阅读体验
- 用户可以切换日间/夜间模式保护视力

#### 2.2.4 标注功能
**功能描述**
- 添加书签
- 添加笔记
- 文本高亮（多种颜色）
- 文本下划线
- 文本加粗
- 文本斜体
- 文本阴影
- 标注导出

**用户场景**
- 用户可以在重要页面添加书签以便快速返回
- 用户可以记录阅读心得和笔记
- 用户可以高亮重点内容以便复习

#### 2.2.5 文字转语音（TTS）
**功能描述**
- 语音合成阅读
- 语音速度调节
- 音量调节
- 语音类型选择（系统可用语音）
- 播放/暂停/停止控制

**用户场景**
- 用户可以听书模式阅读，解放双眼
- 用户可以调整语速适应自己的聆听习惯

#### 2.2.6 翻译和词典
**功能描述**
- AI翻译功能
- AI词典查询
- 文本翻译
- 多语言支持

**用户场景**

## 5. 业务流程

### 5.1 图书导入流程
1. 用户选择导入方式（本地/云端）
2. 选择文件或配置云存储
3. 系统解析文件元数据
4. 生成图书封面
5. 添加到图书列表
6. 保存到数据库

### 5.2 阅读流程
1. 用户从列表选择图书
2. 系统加载图书内容
3. 恢复上次阅读位置
4. 渲染阅读界面
5. 记录阅读进度
6. 自动保存标注和笔记

### 5.3 同步流程
1. 用户配置云存储服务
2. 系统验证连接
3. 上传本地数据到云端
4. 下载云端更新
5. 合并数据冲突
6. 更新本地数据库
