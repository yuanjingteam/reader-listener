# Koodo Reader 开发文档

## 1. 项目概述

### 1.1 项目简介
Koodo Reader 是一款基于 Electron + React + TypeScript 开发的跨平台电子书阅读器。项目采用模块化架构，支持多种电子书格式，提供丰富的阅读功能和云端同步能力。

### 1.2 技术栈总览
- **桌面框架**: Electron 34.0.1
- **前端框架**: React 17.0.2
- **开发语言**: TypeScript 5.9.3
- **状态管理**: Redux + Redux Thunk
- **路由**: React Router DOM 5.2.0
- **国际化**: i18next 20.2.4
- **数据库**: better-sqlite3 11.6.0
- **构建工具**: React Scripts 5.0.1, Electron Builder 26.0.12

## 8. 开发规范

### 8.1 代码规范

#### 8.1.1 TypeScript规范
- 所有文件必须使用TypeScript
- 严格类型检查（strict mode）
- 接口定义使用 `interface`，类型别名使用 `type`
- 避免使用 `any` 类型

```typescript
// 好的实践
interface BookModel {
  key: string;
  title: string;
  author: string;
  createTime: number;
}

function getBook(key: string): BookModel | null {
  // ...
}

// 不好的实践
function getBook(key: any): any {
  // ...
}
```

#### 8.1.2 React规范
- 函数式组件优先
- 使用 Hooks 管理状态
- Props接口定义

```typescript
interface BookCardProps {
  book: BookModel;
  onClick: (book: BookModel) => void;
}

const BookCard: React.FC<BookCardProps> = ({ book, onClick }) => {
  return <div onClick={() => onClick(book)}>{book.title}</div>;
};
```

#### 8.1.3 命名规范
- 组件: PascalCase (`BookCard.tsx`)
- 工具函数: camelCase (`formatDate.ts`)
- 常量: UPPER_SNAKE_CASE (`MAX_BOOK_COUNT`)
- 接口: PascalCase + I前缀 (`IBookProps`)
- 类型: PascalCase (`BookType`)

### 8.2 文件组织规范

#### 8.2.1 组件文件结构
```typescript
// component.tsx
import React from "react";
import "./interface";  // 接口定义
import "./component.css"; // 样式文件

const Component: React.FC<Props> = (props) => {
  // 组件实现
};

export default Component;
```

#### 8.2.2 目录命名
- 复数形式用于集合: `components/`, `dialogs/`
- 单数形式用于单例: `router/`, `store/`

```typescript
const LazyImage = ({ src, alt }) => {
  const [loaded, setLoaded] = useState(false);
  const imgRef = useRef();

  useEffect(() => {
    const observer = new IntersectionObserver((entries) => {
      if (entries[0].isIntersecting) {
        setLoaded(true);
        observer.disconnect();
      }
    });
    observer.observe(imgRef.current);
    return () => observer.disconnect();
  }, []);

  return <img ref={imgRef} src={loaded ? src : placeholder} alt={alt} />;
};
```

## 12. 部署指南

### 12.1 CI/CD

#### 12.1.1 GitHub Actions
```yaml
name: Build and Release
on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [macos-latest, windows-latest, ubuntu-latest]
    steps:
      - uses: actions/checkout@v2
      - name: Setup pnpm
        uses: pnpm/action-setup@v2
        with:
          version: 8
      - name: Install dependencies
        run: pnpm install
      - name: Build
        run: pnpm release
      - name: Upload artifacts
        uses: actions/upload-artifact@v2
        with:

          path: dist/*
```
